
# HAYAA HIJAB

A modern full-stack e-commerce platform for a luxury hijab fashion brand.

## Technology Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- Python
- FastAPI
- PostgreSQL

### Other Technologies
- Stripe
- Cloudinary
- Docker
- Pytest
- Playwright
- Git and GitHub

## Project Features

- Product catalogue
- Customer authentication
- Shopping cart
- Secure checkout
- Order management
- Admin dashboard
